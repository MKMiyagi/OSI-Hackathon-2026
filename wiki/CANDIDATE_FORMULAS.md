# Candidate formulas (overnight 1-3 ledger) — for human review Wednesday

Source: ledger/results.csv (60 runs, 754 scored Pareto rows). Selection rule: lowest val_mae at the stated complexity, one entry per distinct set of variables (so the many constant-only variants of one equation are collapsed; "runs" = number of runs in which that variable set appears at all, any complexity). Equations that use m_MeltingT or m_SpaceGroupNumber (42 rows, best 3.9709 from overnight 1) are excluded as unphysical (reviewer recommendation; later searches hide those features).
NOT evaluated on test and must not be. Every MAE below is a development-set (val, reused) number: data/splits/val.csv was used to pick descriptors, equations and complexity windows, so none is a held-out estimate (see wiki/RESEARCH_REVIEW_3_VERDICT.md). Physical readings are post hoc; no formula is established as a physical law. Target is hv_chen (Chen applied to DFT B,G), not measured hardness. Equations output GPa through fitted constants; dimensionless inputs (chi, Row, counts) are combined with implicit unit coefficients, so none is dimensionally derived. Magpie features are composition means: m_GSvolume_pa = ground-state volume per atom (A^3), m_NValence/m_NdValence/m_NsValence/m_NpValence/m_NfValence = mean valence electrons (total / d / s / p / f), m_NUnfilled/m_NdUnfilled/m_NpUnfilled = mean unfilled valence states, m_Row = periodic-table row, m_MendeleevNumber, m_GSbandgap (eV).
