## Claimed goal
"A compact, physically interpretable, composition-only formula for Vickers hardness that beats
Chen (2011) on held-out chemical families", found via PySR symbolic regression over hand-written,
physically motivated descriptors, generated by an overnight autonomous agent loop (Claude Code +
ARIS) with Codex as per-cycle reviewer. Metric: MAE (GPa) on data/splits/val.csv via eval/score.py.
Test set is evaluated once by a human.

## Executor's own concerns (hypotheses — confirm or refute against the files)
1. **Label circularity.** smoke_pysr.py's docstring says brgoch_superhard_training has no measured
   hardness and the label is hv_chen = Chen(G, B) computed from (DFT) moduli. If the target IS the
   Chen model, "beat Chen" is ill-posed (Chen has zero error on its own label), and the project
   reduces to "approximate Chen(DFT B,G) from composition". Is there a defensible reframing, or is a
   measured-Hv dataset mandatory?
2. **Baseline definition.** Chen requires G and B, not composition. What does "beats Chen" mean in
   a composition-only setting — Chen applied to which moduli (DFT? ML-predicted from composition?)?
3. **Missing infrastructure.** data/splits/, eval/score.py, sr/run_pysr.py appear absent, though
   CLAUDE.md calls them fixed/frozen. "Held-out chemical families" split is undefined.
4. **Quarantine.** settings.json denies only the Read tool; Bash (cat) is not covered. Out of scope
   per threat model? (Cooperating operator, but an autonomous agent is not the operator.)
5. **Multiple comparisons / val overfitting.** Up to 12 cycles/night × many Pareto points, each
   scored on the same val set; the "best" is selected on val. How much optimism does that introduce,
   and what's the minimal guard?
6. matbench_glass is downloaded but unrelated to hardness.
7. Rules say wiki/ but the ARIS wiki was just initialized at research-wiki/.
